Water Consumption Pattern and Seasonal Usage Analysis

Project Description

This project analyzes water consumption patterns using Python and Exploratory Data Analysis (EDA).

It studies how temperature and seasonal changes affect water consumption.

Objectives

- Analyze daily water consumption.
- Study the relationship between temperature and water usage.
- Compare water consumption across seasons.
- Perform weekly and monthly time series analysis.
- Visualize patterns using graphs.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Dataset

The project uses a synthetically generated dataset containing 365 days of sample data.

Columns:

- Date
- Temperature
- Water_Consumption
- Season
- Household_Size

Analysis Performed

- Dataset inspection and statistical analysis
- Scatter plot
- Correlation heatmap
- Regression plot
- Monthly consumption trend
- Seasonal consumption analysis
- Weekly consumption trend

Project Type

Academic EDA Project – Units 4 and 5.
